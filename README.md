# briandconnelly's Plugin Marketplace

Skills, MCP servers, and more as Claude Code plugins.

## Setup

Add this marketplace to Claude Code:

```
/plugin marketplace add briandconnelly/briandconnelly-plugins
```

## Available Plugins

Install a plugin with `/plugin install <plugin>@briandconnelly-plugins`.

| **Plugin** | **Description** |
| --- | --- |
| [ipinfo](ipinfo/) | MCP server for getting IP address details, location, and network information via ipinfo.io |
| [orb-cloud](orb-cloud/) | MCP server for managing Orb Cloud organizations and devices |
| [orbnet](orbnet/) | MCP server for monitoring internet quality via Orb Local API |
| [tempest](tempest/) | MCP server for accessing WeatherFlow Tempest personal weather station data |
